# ChatArchiver
برنامه ویندوزی برای تبدیل خروجی رسمی (Export) چت‌های ChatGPT و Claude به آرشیو قابل جستجو روی کامپیوتر.

## ساخت exe
1. یک ریپازیتوری جدید در GitHub بسازید و همه فایل‌ها را آپلود کنید (شامل پوشه .github).
2. تب Actions ← Build Windows EXE ← Run workflow.
3. بعد از چند دقیقه، از پایین صفحه‌ی همان اجرا، Artifact به نام ChatArchiver-windows را دانلود کنید.
